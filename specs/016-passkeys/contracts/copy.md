# Textos das passkeys (português europeu)

| Onde | Texto |
|---|---|
| Login, botão | Entrar com passkey · «Digital, rosto ou PIN do telemóvel» |
| Login, cancelado | O início de sessão foi cancelado. Pode tentar novamente quando quiser. |
| Login, passkey inválida | Esta passkey já não é válida. Entre com Google. |
| Login, limite | Demasiadas tentativas. Aguarde um minuto e tente novamente. |
| Login, outro erro | Não foi possível entrar com a passkey. Tente novamente ou entre com Google. |
| Conta, título | Entrar com passkey |
| Conta, texto | Entre com a digital, o rosto ou o PIN do telemóvel, sem passar pela Google. A digital nunca sai do telemóvel. |
| Conta, linha | Passkey criada a {data} · «Último uso a {data}» / «Ainda não usada» |
| Conta, botões | Adicionar passkey neste telemóvel · Remover |
| Conta, confirmação | Remover esta passkey? · «Deixa de poder entrar com ela. Pode sempre entrar com Google.» · Remover passkey · Cancelar |
| Conta, sem suporte | Este dispositivo não permite criar passkeys. |
| Conta, erros | Este telemóvel já tem uma passkey desta conta. · Não foi possível adicionar a passkey. Tente novamente. · Não foi possível remover a passkey. Tente novamente. · Não foi possível carregar as passkeys. |
| Início, oferta | Entrar mais depressa · «Ative a passkey e entre com a digital, o rosto ou o PIN do telemóvel.» · Ativar · Agora não |
| Eliminar conta | As passkeys registadas |
| Política | Se ativar a entrada com passkey: a chave pública e as datas de criação e de último uso. A digital, o rosto e o PIN nunca saem do telemóvel. |
